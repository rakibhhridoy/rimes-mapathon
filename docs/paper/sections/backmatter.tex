\section*{Data and code availability}

The pipeline, region configurations, dashboard and test suite are available at \url{https://github.com/rakibhhridoy/rimes-mapathon} under the MIT licence. Input data and outputs for all four regions are packaged per region with a manifest of checksums and licences at \url{https://doi.org/10.5281/zenodo.19233968}. \pending{publish the new version of the Zenodo archive, which replaces GADM with geoBoundaries, and cite its version DOI here.} Every figure in this paper is written into the text by the analysis scripts in the code repository directly from the pipeline outputs, so a rerun of the pipeline updates text and results together. The results are published through an open dashboard at \url{https://fermium.systems/hazmapper}, which shows the risk maps, rankings and per-unit summaries without a sign-in and states the limitations of Section~\ref{sec:discussion} beside the maps. An earlier technical report on this system, prepared for the RIMES Mapathon in March 2026, contained errors that were found in a later review, the most serious being a coordinate-system error that left every training label at zero. Each error and its correction is listed in the technical documentation in the code repository, and no result of that report is used here.
