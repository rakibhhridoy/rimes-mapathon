ABSTRACT (156 words)
--------------------
Flood susceptibility maps for Bangladesh are usually trained on a few hundred surveyed points and scored on a random share of the same points, so their accuracy says little about unmapped ground. Fermium Hazard Mapper is an open Python pipeline and web application that trains flood models on extents mapped from Sentinel-1 radar, scores every model on whole areas held out from training, and publishes risk for each mapped asset and administrative unit, with one configuration file driving each region. Across a national partition of 8 flood regions, covering all 61 lowland districts and 114,569 assets, the default model reaches an AUC of 0.724 to 0.914 on held-out 10 km blocks, and training on radar-observed floods beats training on terrain-threshold labels in every region. Every comparison runs on identical held-out areas and reruns with one command, so another group can check any claim about a model or a data source. Results are served openly at https://fermium.systems/hazmapper.

DATA AVAILABILITY
-----------------
The code is at https://github.com/rakibhhridoy/rimes-mapathon, and the release the article describes is archived at https://doi.org/10.5281/zenodo.23108192. Input data and outputs for the three validation regions and the landslide region are archived at https://doi.org/10.5281/zenodo.23108572, and the national partition is reproduced by the configuration files in the repository. A single command, python scripts/demo.py, downloads a validation region's archive, reruns the pipeline on it without Earth Engine in a few minutes, and checks every headline figure against the archived outputs.
